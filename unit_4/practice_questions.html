4.6 CSS Properties

Q1. Explain the CSS background properties with examples. (4.6.1 Backgrounds)

Answer:

CSS provides several properties to style element backgrounds:

Property Description Example Values
background-color Sets the background color red, #ff0000, rgb(255,0,0)
background-image Sets a background image url('image.jpg')
background-repeat How image repeats repeat, no-repeat, repeat-x, repeat-y
background-position Position of background image center, top left, 50% 50%
background-size Size of background image cover, contain, 100px 200px
background-attachment Fixed or scrolls with page scroll, fixed, local 
.hero-section {
    background-color: #f0f0f0;
    background-image: url('banner.jpg');
    background-repeat: no-repeat;
    background-position: center;
    background-size: cover;
}

/* Shorthand */
.hero-section {
    background: #f0f0f0 url('banner.jpg') no-repeat center/cover;
}

Q2. Write CSS to create a full-screen background image that stays fixed while scrolling.

Answer:

body {
    background-image: url('background.jpg');
    background-size: cover;
    background-position: center;
    background-repeat: no-repeat;
    background-attachment: fixed;
    min-height: 100vh;
}

Explanation:

  • background-size: cover - Image covers entire viewport
  • background-attachment: fixed - Image stays fixed while content scrolls
  • min-height: 100vh - Ensures body is at least full viewport height

Q4. Explain the CSS margin property with examples. (4.6.2 Margin)

Answer:

margin creates space outside an element's border, separating it from other elements.

/* Individual sides */
.box {
    margin-top: 10px;
    margin-right: 20px;
    margin-bottom: 10px;
    margin-left: 20px;
}

/* Shorthand - 4 values (top, right, bottom, left) */
.box { margin: 10px 20px 10px 20px; }

/* Shorthand - 2 values (top-bottom, left-right) */
.box { margin: 10px 20px; }

/* Shorthand - 1 value (all sides) */
.box { margin: 10px; }

/* Auto margin for horizontal centering */
.centered {
    width: 300px;
    margin: 0 auto;
}

Q7. Explain CSS height and width properties. (4.6.4 Height, 4.6.5 Width)

Answer:

The width and height properties set the dimensions of an element's content area.

Property Description Values
width Sets the width 200px, 50%, auto
height Sets the height 100px, 50vh, auto
max-width Maximum width limit 500px, 100%
min-width Minimum width limit 200px, 50%
max-height Maximum height limit 400px, 80vh
min-height Minimum height limit 100px, 50vh 
.fixed-box {
    width: 300px;
    height: 200px;
}

.responsive-box {
    width: 100%;
    max-width: 600px;
    min-height: 200px;
}

.full-screen {
    width: 100vw;   /* 100% viewport width */
    height: 100vh;  /* 100% viewport height */
}

Q16. What is the font shorthand property? Write CSS using font shorthand.

Answer:

The font shorthand property allows setting multiple font properties in one declaration.

Syntax: font: font-style font-variant font-weight font-size/line-height font-family;

/* Using individual properties */
p {
    font-style: italic;
    font-weight: bold;
    font-size: 16px;
    line-height: 1.5;
    font-family: Arial, sans-serif;
}

/* Using shorthand */
p {
    font: italic bold 16px/1.5 Arial, sans-serif;
}

Q17. Explain the difference between em, rem, and px units for font-size.

Answer:

Unit Description Example
px Absolute unit, fixed size in pixels font-size: 16px;
em Relative to parent element's font-size font-size: 1.5em; (1.5 times parent)
rem Relative to root element's font-size (html) font-size: 2rem; (2 times root) 
html { font-size: 16px; }  /* Root font-size */

.parent { font-size: 20px; }
.child-em { font-size: 1.5em; }   /* 30px (1.5 * 20px) */
.child-rem { font-size: 1.5rem; } /* 24px (1.5 * 16px) */

4.10 Line Height

Q21. Explain the line-height property and its different value types.

Answer:

line-height sets the height of a line box, controlling the spacing between lines of text.

Value Type Example Description
Number (unitless) line-height: 1.5; 1.5 times the font-size (recommended)
Length line-height: 24px; Fixed line height in pixels
Percentage line-height: 150%; 150% of the font-size

p {

}

4.11 Box Model

Q23. Explain the CSS Box Model with a diagram description.

Answer:

The CSS Box Model describes how elements are structured with four areas:

  1. Content - The actual content (text, images)
  2. Padding - Space between content and border (inside)
  3. Border - The border around the padding
  4. Margin - Space outside the border (between elements)
Margin
Border
Padding
Content 
.box {
    width: 200px;        /* Content width */
    height: 100px;       /* Content height */
    padding: 20px;       /* Inside spacing */
    border: 5px solid black;
    margin: 30px;        /* Outside spacing */
}

Q24. Calculate the total width of an element with: width: 200px, padding: 20px, border: 5px, margin: 10px.

Answer:

With default box-sizing (content-box):

  • Content width: 200px
  • Left padding: 20px + Right padding: 20px = 40px
  • Left border: 5px + Right border: 5px = 10px
  • Left margin: 10px + Right margin: 10px = 20px

Total width = 200 + 40 + 10 + 20 = 270px

Element box width (without margin) = 200 + 40 + 10 = 250px

Q25. Explain the box-sizing property and its values.

Answer:

box-sizing determines how the total width and height of an element is calculated.

Value Description
content-box Default. Width/height only includes content. Padding and border are added outside.
border-box Width/height includes content, padding, and border. More predictable sizing. 
/* Recommended for easier layouts */
* {
    box-sizing: border-box;
}

.box {
    width: 200px;
    padding: 20px;
    border: 5px solid black;
    /* With border-box: total width stays 200px */
    /* Content area becomes 200 - 40 - 10 = 150px */
}

4.12 Working with Images

Q27. How do you make an image responsive using CSS?

Answer:

A responsive image scales with its container while maintaining aspect ratio.

img {
    max-width: 100%;  /* Never exceed container width */
    height: auto;     /* Maintain aspect ratio */
    display: block;   /* Remove bottom gap */
}

For background images:

.responsive-bg {
    background-image: url('image.jpg');
    background-size: cover;      /* Cover entire container */
    background-position: center; /* Center the image */
    background-repeat: no-repeat;
}

Q28. Explain background-size property values: auto, cover, and contain.

Answer:

Value Description
auto Default. Image displays at its original size.
cover Scales image to cover entire container. May crop parts of image.
contain Scales image to fit within container. Shows entire image, may have empty space.
100% 100% Stretches image to fill container (may distort). 
.hero-banner {
    height: 300px;
    background-image: url('banner.jpg');
    background-size: cover;
    background-position: center;
}

background-repeat controls how background images are repeated.

Value Description

repeat-y Repeats only vertically.
