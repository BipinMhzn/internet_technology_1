4.1 INTRODUCTION TO CSS
================================================================================

WHAT IS CSS?
------------
CSS (Cascading Style Sheets) is a stylesheet language used to describe the
presentation of a document written in HTML. It controls the visual appearance
of web pages including layout, colors, fonts, and spacing.

The Three Pillars of Web Development:
- HTML: Structure and content (the skeleton)
- CSS: Presentation and styling (the skin and clothes)
- JavaScript: Behavior and interactivity (the muscles)

Why CSS?
--------
1. Separation of Concerns: Separates content (HTML) from presentation (CSS)
2. Consistency: Apply same styles across multiple pages
3. Maintainability: Change appearance without modifying HTML
4. Efficiency: Single stylesheet can style entire website
5. Flexibility: Multiple style options for same content
6. Accessibility: Better control for different devices and users

History of CSS:
---------------
- CSS1 (1996): Basic styling capabilities
- CSS2 (1998): Positioning, z-index, media types
- CSS2.1 (2011): Fixed bugs and inconsistencies
- CSS3 (2011+): Modular approach, new features (flexbox, grid, animations)

CSS Versions/Modules:
    CSS3 introduced modular approach:
    - Selectors Level 3
    - Box Model
    - Backgrounds and Borders
    - Text Effects
    - 2D/3D Transformations
    - Animations
    - Flexbox
    - Grid Layout
    - Media Queries

4.2 CSS SYNTAX
================================================================================

BASIC CSS SYNTAX
----------------
CSS consists of rules that define how HTML elements should be displayed.

Structure of a CSS Rule:
    ┌─────────────────────────────────────────┐
    │  selector {                             │
    │      property: value;                   │
    │      property: value;                   │
    │  }                                      │
    └─────────────────────────────────────────┘

Components:
- Selector: Targets HTML element(s) to style
- Declaration Block: Contains one or more declarations in { }
- Declaration: A property-value pair
- Property: The style attribute to change (color, font-size, etc.)
- Value: The setting for the property
- Semicolon: Separates declarations (required)

Example:
    h1 {
        color: blue;
        font-size: 24px;
        text-align: center;
    }

    Breakdown:
    - Selector: h1 (targets all <h1> elements)
    - Properties: color, font-size, text-align
    - Values: blue, 24px, center

Multiple Selectors:
    /* Same styles for multiple selectors */
    h1, h2, h3 {
        color: navy;
        font-family: Arial, sans-serif;
    }

Declaration Formatting:
    /* Single line (for one property) */
    p { color: red; }

    /* Multiple lines (recommended for readability) */
    p {
        color: red;
        font-size: 16px;
        line-height: 1.5;
        margin-bottom: 10px;
    }

Case Sensitivity:
- Selectors: Case-sensitive for class/ID names
- Properties: Case-insensitive (lowercase recommended)
- Values: Depends on context (URLs are case-sensitive)

    /* These are different */
    .MyClass { }
    .myclass { }

    /* These are the same */
    COLOR: red;
    color: red;

4.3 USING CSS WITH HTML
================================================================================

There are three ways to apply CSS to HTML documents:

1. INLINE CSS
-------------
CSS written directly in the HTML element's style attribute.

Syntax:
    <element style="property: value; property: value;">

Example:
    <h1 style="color: blue; font-size: 24px;">Hello World</h1>
    <p style="color: red; margin: 10px;">This is a paragraph.</p>

Characteristics:
- Highest specificity (overrides other styles)
- Applies to single element only
- Mixes content with presentation
- Difficult to maintain
- Not recommended for large projects

Use Cases:
- Quick testing
- Email templates (limited CSS support)
- Dynamic styles via JavaScript
- Overriding specific elements

2. INTERNAL CSS (Embedded CSS)
------------------------------
CSS written inside <style> tags in the HTML document's <head> section.

Syntax:
    <head>
        <style>
            selector {
                property: value;
            }
        </style>
    </head>

Example:
    <!DOCTYPE html>
    <html>
    <head>
        <title>Internal CSS Example</title>
        <style>
            body {
                background-color: #f0f0f0;
                font-family: Arial, sans-serif;
            }

            h1 {
                color: navy;
                text-align: center;
            }

            p {
                color: #333;
                line-height: 1.6;
            }
        </style>
    </head>
    <body>
        <h1>Welcome</h1>
        <p>This is styled with internal CSS.</p>
    </body>
    </html>

Characteristics:
- Styles apply to single page only
- No additional HTTP request
- Good for single-page styles
- Increases HTML file size

Use Cases:
- Single page websites
- Page-specific styles
- Prototyping

3. EXTERNAL CSS
---------------
CSS written in separate .css files and linked to HTML documents.

HTML File (index.html):
    <!DOCTYPE html>
    <html>
    <head>
        <title>External CSS Example</title>
        <link rel="stylesheet" href="styles.css">
        <!-- Or multiple stylesheets -->
        <link rel="stylesheet" href="reset.css">
        <link rel="stylesheet" href="main.css">
    </head>
    <body>
        <h1>Welcome</h1>
        <p>This is styled with external CSS.</p>
    </body>
    </html>

CSS File (styles.css):
    body {
        background-color: #f0f0f0;
        font-family: Arial, sans-serif;
    }

    h1 {
        color: navy;
        text-align: center;
    }

    p {
        color: #333;
        line-height: 1.6;
    }

The <link> Element Attributes:
    <link rel="stylesheet"       /* Relationship: stylesheet */
          href="styles.css"      /* Path to CSS file */
          type="text/css"        /* Optional in HTML5 */
          media="screen">        /* Optional: media type */

Alternative: @import (inside CSS or <style>):
    <style>
        @import url('styles.css');
        @import url('print.css') print;
    </style>

    /* Or in CSS file */
    @import url('reset.css');
    @import url('typography.css');

    Note: @import is slower than <link> - not recommended

Characteristics:
- Separation of concerns
- Reusable across multiple pages
- Browser caching (faster subsequent loads)
- Easier maintenance
- Best practice for production

COMPARISON OF CSS METHODS
-------------------------
| Aspect        | Inline      | Internal    | External     |
|---------------|-------------|-------------|--------------|
| Location      | HTML element| <head>      | Separate file|
| Scope         | Single elem | Single page | Multiple pages|
| Reusability   | None        | Limited     | High         |
| Maintenance   | Difficult   | Medium      | Easy         |
| Caching       | No          | No          | Yes          |
| Specificity   | Highest     | Normal      | Normal       |
| Best For      | Testing     | Single page | Production   |

Priority Order (Cascade):
1. Inline styles (highest priority)
2. Internal styles
3. External styles
4. Browser defaults (lowest priority)

Note: !important and specificity can override this order.

4.4 CSS SELECTORS
================================================================================

Selectors are patterns used to select and style HTML elements.

BASIC SELECTORS
---------------

1. Universal Selector (*)
-------------------------
Selects all elements.

    * {
        margin: 0;
        padding: 0;
        box-sizing: border-box;
    }

2. Element/Type Selector
------------------------
Selects all elements of a given type.

    p {
        color: #333;
        line-height: 1.6;
    }

    h1 {
        font-size: 32px;
    }

    div {
        background-color: #f0f0f0;
    }

3. Class Selector (.)
---------------------
Selects elements with a specific class attribute.

    .highlight {
        background-color: yellow;
    }

    .btn {
        padding: 10px 20px;
        border-radius: 5px;
    }

    /* Multiple classes */
    .btn.btn-primary {
        background-color: blue;
        color: white;
    }

    HTML:
    <p class="highlight">Highlighted text</p>
    <button class="btn btn-primary">Click Me</button>

4. ID Selector (#)
------------------
Selects element with a specific ID (unique per page).

    #header {
        background-color: #333;
        padding: 20px;
    }

    #main-content {
        max-width: 1200px;
        margin: 0 auto;
    }

    HTML:
    <header id="header">...</header>
    <main id="main-content">...</main>

    Note: IDs should be unique; use classes for repeated styles.

5. Attribute Selector
---------------------
Selects elements based on attributes.

    /* Has attribute */
    [disabled] {
        opacity: 0.5;
    }

    /* Exact value */
    [type="text"] {
        border: 1px solid #ccc;
    }

    /* Contains value in space-separated list */
    [class~="btn"] {
        cursor: pointer;
    }

    /* Starts with value */
    [href^="https"] {
        color: green;
    }

    /* Ends with value */
    [href$=".pdf"] {
        color: red;
    }

    /* Contains value anywhere */
    [href*="example"] {
        font-weight: bold;
    }

    /* Starts with value or value followed by hyphen */
    [lang|="en"] {
        font-family: Arial;
    }

COMBINATOR SELECTORS
--------------------

1. Descendant Selector (space)
------------------------------
Selects all descendants (children, grandchildren, etc.)

    div p {
        color: blue;
    }

    /* Any p inside any div */
    <div>
        <p>Blue text</p>           <!-- Selected -->
        <section>
            <p>Also blue</p>       <!-- Selected -->
        </section>
    </div>

2. Child Selector (>)
---------------------
Selects only direct children.

    div > p {
        color: red;
    }

    <div>
        <p>Red text</p>            <!-- Selected -->
        <section>
            <p>Not red</p>         <!-- NOT selected -->
        </section>
    </div>

3. Adjacent Sibling Selector (+)
--------------------------------
Selects element immediately after another.

    h1 + p {
        font-size: 1.2em;
    }

    <h1>Title</h1>
    <p>First paragraph</p>         <!-- Selected -->
    <p>Second paragraph</p>        <!-- NOT selected -->

4. General Sibling Selector (~)
-------------------------------
Selects all siblings after an element.

    h1 ~ p {
        color: gray;
    }

    <h1>Title</h1>
    <p>First paragraph</p>         <!-- Selected -->
    <p>Second paragraph</p>        <!-- Selected -->
    <div>Not a paragraph</div>
    <p>Third paragraph</p>         <!-- Selected -->

PSEUDO-CLASS SELECTORS
----------------------
Select elements based on state or position.

1. Link States:
    a:link {
        color: blue;           /* Unvisited link */
    }

    a:visited {
        color: purple;         /* Visited link */
    }

    a:hover {
        color: red;            /* Mouse over */
    }

    a:active {
        color: orange;         /* Being clicked */
    }

    /* Order matters: LoVe HAte (Link, Visited, Hover, Active) */

2. Form States:
    input:focus {
        border-color: blue;
        outline: none;
    }

    input:disabled {
        background-color: #eee;
    }

    input:enabled {
        background-color: white;
    }

    input:checked {
        accent-color: green;
    }

    input:required {
        border-left: 3px solid red;
    }

    input:valid {
        border-color: green;
    }

    input:invalid {
        border-color: red;
    }

    input:placeholder-shown {
        font-style: italic;
    }

3. Structural Pseudo-classes:
    /* First and last */
    li:first-child {
        font-weight: bold;
    }

    li:last-child {
        border-bottom: none;
    }

    /* Nth child */
    li:nth-child(2) {
        color: red;           /* Second item */
    }

    li:nth-child(odd) {
        background: #f0f0f0;  /* 1st, 3rd, 5th... */
    }

    li:nth-child(even) {
        background: #fff;     /* 2nd, 4th, 6th... */
    }

    li:nth-child(3n) {
        color: blue;          /* Every 3rd item */
    }

    li:nth-child(3n+1) {
        color: green;         /* 1st, 4th, 7th... */
    }

    /* From the end */
    li:nth-last-child(1) {
        /* Same as :last-child */
    }

    /* By type */
    p:first-of-type {
        font-size: 1.2em;
    }

    p:last-of-type {
        margin-bottom: 0;
    }

    p:nth-of-type(2) {
        color: blue;
    }

    /* Only child */
    p:only-child {
        text-align: center;
    }

    /* Empty elements */
    div:empty {
        display: none;
    }

    /* Root element */
    :root {
        --primary-color: blue;
    }

4. Negation Pseudo-class:
    /* Select all except */
    p:not(.intro) {
        color: gray;
    }

    li:not(:last-child) {
        border-bottom: 1px solid #ccc;
    }

    input:not([type="submit"]) {
        border: 1px solid #ccc;
    }

PSEUDO-ELEMENT SELECTORS
------------------------
Style specific parts of elements.

    /* First letter */
    p::first-letter {
        font-size: 2em;
        font-weight: bold;
        float: left;
    }

    /* First line */
    p::first-line {
        font-weight: bold;
    }

    /* Before content */
    .required::before {
        content: "* ";
        color: red;
    }

    /* After content */
    a[href^="http"]::after {
        content: " ↗";
    }

    /* Selection highlight */
    ::selection {
        background-color: yellow;
        color: black;
    }

    /* Placeholder text */
    input::placeholder {
        color: #999;
        font-style: italic;
    }

SELECTOR GROUPING
-----------------
Apply same styles to multiple selectors.

    h1, h2, h3, h4, h5, h6 {
        font-family: Georgia, serif;
        color: #333;
    }

    .btn-primary,
    .btn-secondary,
    .btn-danger {
        padding: 10px 20px;
        border: none;
        border-radius: 5px;
        cursor: pointer;
    }

4.5 CSS COMMENTS
================================================================================

Comments are used to explain code and are ignored by browsers.

SINGLE-LINE COMMENTS
--------------------
    /* This is a single-line comment */
    p {
        color: blue;  /* Inline comment */
    }

MULTI-LINE COMMENTS
-------------------
    /*
     * This is a multi-line comment
     * It can span multiple lines
     * Used for documentation
     */
    .container {
        max-width: 1200px;
    }

    /*
    ========================================
    SECTION: HEADER STYLES
    ========================================
    */

COMMENTING FOR ORGANIZATION
---------------------------
    /* ============================================
       TABLE OF CONTENTS
       ============================================
       1. Reset
       2. Typography
       3. Layout
       4. Components
       5. Utilities
       ============================================ */

    /* 1. Reset
       -------------------------------------------- */
    * {
        margin: 0;
        padding: 0;
    }

    /* 2. Typography
       -------------------------------------------- */
    body {
        font-family: Arial, sans-serif;
    }

COMMENTING OUT CODE
-------------------
    .button {
        background-color: blue;
        /* background-color: red; */  /* Disabled */
        color: white;
    }

BEST PRACTICES
--------------
- Comment complex or non-obvious code
- Use comments to organize sections
- Don't over-comment obvious code
- Keep comments up to date
- Use consistent comment style

4.6.1 BACKGROUNDS
-----------------

background-color:
    body {
        background-color: #f0f0f0;
        background-color: rgb(240, 240, 240);
        background-color: rgba(0, 0, 0, 0.5);  /* With transparency */
        background-color: transparent;
    }

background-image:
    .hero {
        background-image: url('image.jpg');
        background-image: url('../images/bg.png');
        background-image: linear-gradient(to right, red, blue);
        background-image: radial-gradient(circle, white, black);
    }

    /* Multiple backgrounds */
    .multi-bg {
        background-image:
            url('overlay.png'),
            url('background.jpg');
    }

background-repeat:
    .element {
        background-repeat: repeat;     /* Default: tile both ways */
        background-repeat: repeat-x;   /* Tile horizontally */
        background-repeat: repeat-y;   /* Tile vertically */
        background-repeat: no-repeat;  /* Don't tile */
        background-repeat: space;      /* Tile with equal spacing */
        background-repeat: round;      /* Tile and resize to fit */
    }

background-position:
    .element {
        background-position: left top;
        background-position: center center;
        background-position: right bottom;
        background-position: 50% 50%;
        background-position: 100px 50px;
    }

background-size:
    .element {
        background-size: auto;          /* Original size */
        background-size: cover;         /* Cover entire area */
        background-size: contain;       /* Fit within area */
        background-size: 100px 200px;   /* Width height */
        background-size: 50% auto;      /* Percentage */
    }

background-attachment:
    .element {
        background-attachment: scroll;  /* Scrolls with content */
        background-attachment: fixed;   /* Fixed to viewport */
        background-attachment: local;   /* Scrolls with element */
    }

background-origin:
    .element {
        background-origin: padding-box; /* Default */
        background-origin: border-box;
        background-origin: content-box;
    }

background-clip:
    .element {
        background-clip: border-box;  /* Default */
        background-clip: padding-box;
        background-clip: content-box;
        background-clip: text;        /* Text-shaped background */
    }

background (Shorthand):
    .element {
        /* color image position/size repeat attachment */
        background: #f0f0f0 url('bg.jpg') center/cover no-repeat fixed;
    }

    .hero {
        background:
            linear-gradient(rgba(0,0,0,0.5), rgba(0,0,0,0.5)),
            url('hero.jpg') center/cover no-repeat;
    }

4.6.2 BORDER AND MARGIN
-----------------------

BORDER:

border-width:
    .element {
        border-width: 1px;
        border-width: thin;    /* ~1px */
        border-width: medium;  /* ~3px */
        border-width: thick;   /* ~5px */
        border-width: 1px 2px 3px 4px;  /* top right bottom left */
    }

border-style:
    .element {
        border-style: none;
        border-style: solid;
        border-style: dashed;
        border-style: dotted;
        border-style: double;
        border-style: groove;
        border-style: ridge;
        border-style: inset;
        border-style: outset;
    }

border-color:
    .element {
        border-color: red;
        border-color: #333;
        border-color: rgb(255, 0, 0);
        border-color: transparent;
    }

border (Shorthand):
    .element {
        border: 1px solid #333;    /* width style color */
        border-top: 2px dashed red;
        border-right: 1px solid blue;
        border-bottom: 3px double green;
        border-left: none;
    }

border-radius:
    .element {
        border-radius: 5px;        /* All corners */
        border-radius: 50%;        /* Circle/ellipse */
        border-radius: 10px 20px;  /* top-left/bottom-right top-right/bottom-left */
        border-radius: 10px 20px 30px 40px;  /* Each corner */

        /* Individual corners */
        border-top-left-radius: 10px;
        border-top-right-radius: 20px;
        border-bottom-right-radius: 30px;
        border-bottom-left-radius: 40px;
    }

MARGIN:
Margin creates space OUTSIDE the element.

    .element {
        margin: 20px;              /* All sides */
        margin: 10px 20px;         /* Vertical horizontal */
        margin: 10px 20px 30px;    /* Top horizontal bottom */
        margin: 10px 20px 30px 40px;  /* Top right bottom left */

        /* Individual sides */
        margin-top: 10px;
        margin-right: 20px;
        margin-bottom: 30px;
        margin-left: 40px;

        /* Auto for centering */
        margin: 0 auto;            /* Center horizontally */

        /* Negative margins */
        margin-top: -10px;         /* Pull element up */
    }

Margin Collapsing:
    /* Vertical margins of adjacent elements collapse */
    .box1 { margin-bottom: 20px; }
    .box2 { margin-top: 30px; }
    /* Actual gap = 30px (larger margin wins) */

4.6.3 PADDING
-------------
Padding creates space INSIDE the element (between content and border).

    .element {
        padding: 20px;             /* All sides */
        padding: 10px 20px;        /* Vertical horizontal */
        padding: 10px 20px 30px;   /* Top horizontal bottom */
        padding: 10px 20px 30px 40px;  /* Top right bottom left */

        /* Individual sides */
        padding-top: 10px;
        padding-right: 20px;
        padding-bottom: 30px;
        padding-left: 40px;
    }

Difference between Margin and Padding:
    ┌─────────────────────────────────────────┐
    │ MARGIN (outside)                        │
    │  ┌────────────────────────────────────┐ │
    │  │ BORDER                             │ │
    │  │  ┌───────────────────────────────┐ │ │
    │  │  │ PADDING (inside)              │ │ │
    │  │  │  ┌──────────────────────────┐ │ │ │
    │  │  │  │ CONTENT                  │ │ │ │
    │  │  │  └──────────────────────────┘ │ │ │
    │  │  └───────────────────────────────┘ │ │
    │  └────────────────────────────────────┘ │
    └─────────────────────────────────────────┘

4.6.6 COLOR (Color Wheel)
-------------------------

Color Formats:

1. Named Colors:
    color: red;
    color: blue;
    color: rebeccapurple;
    color: transparent;
    /* 140+ named colors available */

2. Hexadecimal:
    color: #ff0000;        /* Red */
    color: #f00;           /* Shorthand */
    color: #ff0000ff;      /* With alpha */

3. RGB (Red, Green, Blue):
    color: rgb(255, 0, 0);
    color: rgb(100%, 0%, 0%);

4. RGBA (with Alpha/Transparency):
    color: rgba(255, 0, 0, 0.5);    /* 50% transparent */
    color: rgba(255, 0, 0, 1);      /* Fully opaque */
    color: rgba(255, 0, 0, 0);      /* Fully transparent */

5. HSL (Hue, Saturation, Lightness):
    color: hsl(0, 100%, 50%);       /* Red */
    color: hsl(120, 100%, 50%);     /* Green */
    color: hsl(240, 100%, 50%);     /* Blue */

    /* Hue: 0-360 (color wheel position)
       Saturation: 0-100% (gray to full color)
       Lightness: 0-100% (black to white) */

6. HSLA (with Alpha):
    color: hsla(0, 100%, 50%, 0.5);

The Color Wheel:
    ┌─────────────────────────────────────────┐
    │              0° / 360°                  │
    │                 RED                     │
    │                  │                      │
    │    330°          │          30°         │
    │   MAGENTA        │       ORANGE         │
    │          \       │       /              │
    │            \     │     /                │
    │   300°       \   │   /       60°        │

================================================================================
4.11 BOX MODEL
================================================================================

Every HTML element is a rectangular box with four areas:

THE CSS BOX MODEL
-----------------
    ┌─────────────────────────────────────────────────────────┐
    │                      MARGIN                             │
    │  ┌───────────────────────────────────────────────────┐  │
    │  │                    BORDER                         │  │
    │  │  ┌─────────────────────────────────────────────┐  │  │
    │  │  │               PADDING                       │  │  │
    │  │  │  ┌───────────────────────────────────────┐  │  │  │
    │  │  │  │                                       │  │  │  │
    │  │  │  │            CONTENT                    │  │  │  │
    │  │  │  │         (width x height)              │  │  │  │
    │  │  │  │                                       │  │  │  │
    │  │  │  └───────────────────────────────────────┘  │  │  │
    │  │  │                                             │  │  │
    │  │  └─────────────────────────────────────────────┘  │  │
    │  │                                                   │  │
    │  └───────────────────────────────────────────────────┘  │
    │                                                         │
    └─────────────────────────────────────────────────────────┘

BOX MODEL COMPONENTS
--------------------

1. Content: The actual content (text, images)
2. Padding: Space between content and border (inside)
3. Border: Surrounds the padding
4. Margin: Space outside the border (between elements)

BOX-SIZING PROPERTY
-------------------

content-box (Default):
    Width/height applies to content only.
    Total width = width + padding + border

    .element {
        box-sizing: content-box;
        width: 200px;
        padding: 20px;
        border: 5px solid black;
    }
    /* Total width = 200 + 40 + 10 = 250px */

border-box (Recommended):
    Width/height includes padding and border.
    Total width = width (padding and border inside)

    .element {
        box-sizing: border-box;
        width: 200px;
        padding: 20px;
        border: 5px solid black;
    }
    /* Total width = 200px (content shrinks to 150px) */

Universal Border-Box:
    /* Apply to all elements */
    *, *::before, *::after {
        box-sizing: border-box;
    }

    /* Or inherit method */
    html {
        box-sizing: border-box;
    }

    *, *::before, *::after {
        box-sizing: inherit;
    }

CALCULATING TOTAL DIMENSIONS
----------------------------

With content-box:
    Total Width = width + padding-left + padding-right + border-left + border-right
    Total Height = height + padding-top + padding-bottom + border-top + border-bottom

    Example:
    width: 300px;
    padding: 20px;
    border: 5px solid black;

    Total Width = 300 + 20 + 20 + 5 + 5 = 350px

With border-box:
    Total Width = width (set value)
    Content Width = width - padding - border

4.13 LAYOUT AND POSITIONING
================================================================================

DISPLAY PROPERTY
----------------

    .element {
        display: block;        /* Full width, new line */
        display: inline;       /* Inline with text flow */
        display: inline-block; /* Inline but accepts width/height */
        display: none;         /* Hidden, removed from flow */
        display: flex;         /* Flexbox container */
        display: grid;         /* Grid container */
    }

Block vs Inline vs Inline-Block:
    ┌─────────────────────────────────────────────────────────────┐
    │ Block Elements (div, p, h1-h6):                            │
    │ ┌─────────────────────────────────────────────────────────┐│
    │ │ Takes full width, starts on new line                    ││
    │ └─────────────────────────────────────────────────────────┘│
    │ ┌─────────────────────────────────────────────────────────┐│
    │ │ Another block element                                   ││
    │ └─────────────────────────────────────────────────────────┘│
    └─────────────────────────────────────────────────────────────┘

    ┌─────────────────────────────────────────────────────────────┐
    │ Inline Elements (span, a, strong):                         │
    │ This is [inline] text with [more inline] elements          │
    │ They flow with text and don't accept width/height          │
    └─────────────────────────────────────────────────────────────┘

    ┌─────────────────────────────────────────────────────────────┐
    │ Inline-Block:                                              │
    │ [Box1] [Box2] [Box3]                                       │
    │ Inline flow but accepts width/height                       │
    └─────────────────────────────────────────────────────────────┘

POSITION PROPERTY
-----------------

1. static (Default):
    .element {
        position: static;
    }
    /* Normal document flow, top/right/bottom/left don't work */

2. relative:
    .element {
        position: relative;
        top: 10px;
        left: 20px;
    }
    /* Offset from normal position, space still reserved */

3. absolute:
    .element {
        position: absolute;
        top: 0;
        right: 0;
    }
    /* Removed from flow, positioned relative to nearest
       positioned ancestor (or viewport) */

4. fixed:
    .element {
        position: fixed;
        top: 0;
        left: 0;
        width: 100%;
    }
    /* Fixed to viewport, doesn't move on scroll */

5. sticky:
    .element {
        position: sticky;
        top: 0;
    }
    /* Normal until scroll position reached, then fixed */

Position Properties:
    .element {
        top: 10px;
        right: 10px;
        bottom: 10px;
        left: 10px;

        /* Shorthand with inset */
        inset: 10px;           /* All sides */
        inset: 10px 20px;      /* Vertical horizontal */
    }

Z-INDEX
-------
Controls stacking order of positioned elements.

    .behind {
        position: relative;
        z-index: 1;
    }

    .infront {
        position: relative;
        z-index: 2;    /* Higher = in front */
    }

    .way-back {
        position: relative;
        z-index: -1;   /* Behind normal flow */
    }

4.14 MEDIA QUERY
================================================================================

Media queries apply styles based on device characteristics.

BASIC SYNTAX
------------
    @media media-type and (condition) {
        /* CSS rules */
    }

MEDIA TYPES
-----------
    @media all { }      /* All devices (default) */
    @media screen { }   /* Screens */
    @media print { }    /* Printed pages */
    @media speech { }   /* Screen readers */

WIDTH-BASED QUERIES
-------------------

    /* Mobile first (min-width) */
    /* Base styles for mobile */

    @media (min-width: 576px) {
        /* Small devices and up */
    }

    @media (min-width: 768px) {
        /* Medium devices and up */
    }

    @media (min-width: 992px) {
        /* Large devices and up */
    }

    @media (min-width: 1200px) {
        /* Extra large devices */
    }

    /* Desktop first (max-width) */
    @media (max-width: 1199px) {
        /* Below extra large */
    }

    @media (max-width: 991px) {
        /* Below large */
    }

    @media (max-width: 767px) {
        /* Below medium (tablets) */
    }

    @media (max-width: 575px) {
        /* Mobile only */
    }

RANGE QUERIES
-------------
    /* Between two widths */
    @media (min-width: 768px) and (max-width: 991px) {
        /* Tablets only */
    }

    /* Modern syntax */
    @media (768px <= width <= 991px) {
        /* Same as above */
    }

OTHER CONDITIONS
----------------

    /* Orientation */
    @media (orientation: portrait) { }
    @media (orientation: landscape) { }

    /* Resolution */
    @media (min-resolution: 2dppx) { }  /* Retina/HiDPI */

    /* Hover capability */
    @media (hover: hover) { }  /* Has hover */
    @media (hover: none) { }   /* Touch devices */

    /* Pointer precision */
    @media (pointer: fine) { }   /* Mouse */
    @media (pointer: coarse) { } /* Touch */

    /* Prefers color scheme */
    @media (prefers-color-scheme: dark) {
        body {
            background: #333;
            color: #fff;
        }
    }

    @media (prefers-color-scheme: light) {
        body {
            background: #fff;
            color: #333;
        }
    }

    /* Reduced motion */
    @media (prefers-reduced-motion: reduce) {
        * {
            animation: none !important;
            transition: none !important;
        }
    }

COMBINING CONDITIONS
--------------------
    /* AND */
    @media screen and (min-width: 768px) and (orientation: landscape) { }

    /* OR (comma) */
    @media (max-width: 600px), (orientation: portrait) { }

    /* NOT */
    @media not print { }

PRACTICAL EXAMPLE
-----------------
    /* Base styles (mobile) */
    .container {
        width: 100%;
        padding: 15px;
    }

    .card {
        width: 100%;
        margin-bottom: 20px;
    }

    /* Tablet */
    @media (min-width: 768px) {
        .container {
            max-width: 750px;
            margin: 0 auto;
        }

        .card {
            width: 48%;
            display: inline-block;
        }
    }

    /* Desktop */
    @media (min-width: 992px) {
        .container {
            max-width: 970px;
        }

        .card {
            width: 31%;
        }
    }

    /* Large Desktop */
    @media (min-width: 1200px) {
        .container {
            max-width: 1170px;
        }
    }

VIEWPORT META TAG
-----------------
Required in HTML for responsive design on mobile:

    <meta name="viewport" content="width=device-width, initial-scale=1.0">
