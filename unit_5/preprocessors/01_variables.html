📝 What are SCSS Variables?

Variables in SCSS allow you to store values (colors, fonts, sizes) and reuse them throughout your stylesheet. They start with $ symbol. When you change a variable, all instances update automatically!

❌ Without Variables (Plain CSS)

.button-primary {
    background-color: #3498db;
    font-family: 'Helvetica', sans-serif;
    padding: 16px;
}

.button-secondary {
    background-color: #2ecc71;
    font-family: 'Helvetica', sans-serif;
    padding: 16px;
}

.card-header {
    color: #3498db;
    font-family: 'Helvetica', sans-serif;
}

/* Problem: If we want to change
   the color, we need to update
   it in MULTIPLE places! */

✅ With Variables (SCSS)

// Define variables once
$primary-color: #3498db;
$secondary-color: #2ecc71;
$font-stack: 'Helvetica', sans-serif;
$spacing: 16px;

.button-primary {
    background-color: $primary-color;
    font-family: $font-stack;
    padding: $spacing;
}

.button-secondary {
    background-color: $secondary-color;
    font-family: $font-stack;
    padding: $spacing;
}

.card-header {
    color: $primary-color;
    font-family: $font-stack;
}

/* Change once, update everywhere! */

💡 Variable Types

// Colors
$primary-color: #3498db;
$secondary-color: rgb(46, 204, 113);
$danger-color: hsl(0, 70%, 60%);

// Numbers
$font-size: 16px;
$spacing-unit: 1rem;
$line-height: 1.5;
$border-width: 2px;

// Strings
$font-stack: 'Helvetica Neue', Arial, sans-serif;
$image-path: '../images/';

// Booleans
$is-rounded: true;
$show-shadow: false;

// Lists (arrays)
$sizes: 12px, 14px, 16px, 18px, 24px;
$breakpoints: 768px, 1024px, 1440px;

// Maps (key-value pairs)
$colors: (
    primary: #3498db,
    secondary: #2ecc71,
    danger: #e74c3c,
    warning: #f39c12
);

// Using map values
.button {
    background: map-get($colors, primary);
}

🔍 Variable Scope

Global Variables

// Global scope
$primary-color: blue;

.header {
    color: $primary-color; // ✅ Works
}

.footer {
    color: $primary-color; // ✅ Works
}

Local Variables

.card {
    // Local scope
    $card-padding: 20px;

    padding: $card-padding; // ✅ Works
}

.button {
    padding: $card-padding; // ❌ Error!
    // Variable not defined in this scope
}

✨ Advanced: Variable Interpolation

// Using variables in selectors and property names
$side: left;
$property: margin;

.element {
    #{$property}-#{$side}: 20px;
    // Compiles to: margin-left: 20px;
}

// Dynamic class names
$theme: dark;

.button-#{$theme} {
    background: #333;
    color: white;
}
// Creates: .button-dark { ... }

🎯 Best Practices

💡 Tips for Using Variables:

  1. Naming Convention: Use descriptive names like $primary-color not $blue
  2. Group Related Variables: Keep colors together, spacing together, etc.
  3. Use a Variables File: Store all variables in _variables.scss
  4. Document Your Variables: Add comments explaining usage
  5. Don't Overuse: Only create variables for values used multiple times

📊 Comparison: SCSS vs CSS Variables

SCSS Variables

// Compiled at build time
$color: blue;

.element {
    color: $color;
}

✅ More powerful features
✅ Can be used in calculations
✅ Available everywhere in SCSS
❌ Cannot change at runtime
❌ Requires compilation

CSS Variables (Custom Properties)

/* Available at runtime */
:root {
    --color: blue;
}

.element {
    color: var(--color);
}

✅ Can change with JavaScript
✅ No compilation needed
✅ Inherit through cascade
❌ Less features
❌ Limited browser support (old)

🎓 Key Takeaways:

  • Variables start with $ in SCSS
  • They store values for reuse throughout your stylesheet
  • Changes to variables update all instances automatically
  • Variables improve maintainability and consistency
  • SCSS variables are compiled to regular CSS values
