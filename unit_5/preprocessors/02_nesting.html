🪆 SCSS Nesting

🎯 Learning Objectives:

  • Understand SCSS nesting to mirror HTML structure
  • Learn to use the parent selector (&)
  • Avoid over-nesting (best practices)
  • Use nesting for pseudo-classes and pseudo-elements

📝 What is Nesting?

Nesting in SCSS allows you to nest CSS selectors in a way that follows the same visual hierarchy of your HTML. It makes your stylesheet more readable and maintainable!

Example 1: Basic Nesting

❌ Without Nesting (Plain CSS)

.navbar {
    background: #333;
    padding: 1rem;
}

.navbar ul {
    list-style: none;
    display: flex;
}

.navbar li {
    margin: 0 1rem;
}

.navbar a {
    color: white;
    text-decoration: none;
}

.navbar a:hover {
    color: #3498db;
}

/* Repetitive! Must type
   .navbar every time */

✅ With Nesting (SCSS)

.navbar {
    background: #333;
    padding: 1rem;

    ul {
        list-style: none;
        display: flex;
    }

    li {
        margin: 0 1rem;
    }

    a {
        color: white;
        text-decoration: none;

        &:hover {
            color: #3498db;
        }
    }
}

/* Cleaner! Mirrors HTML structure */

🔗 The Parent Selector (&)

The & symbol refers to the parent selector. It's incredibly powerful for pseudo-classes, pseudo-elements, and modifier classes! 

.button {
    background: blue;
    color: white;
    padding: 10px 20px;

    // Pseudo-classes
    &:hover {
        background: darkblue;
    }

    &:active {
        background: navy;
    }

    &:disabled {
        opacity: 0.5;
        cursor: not-allowed;
    }

    // Pseudo-elements
    &::before {
        content: '→ ';
    }

    &::after {
        content: ' ←';
    }

    // Modifier classes (BEM style)
    &--primary {
        background: green;
    }

    &--danger {
        background: red;
    }

    // Element classes (BEM style)
    &__icon {
        margin-right: 5px;
    }
}

// Compiles to:
// .button { ... }
// .button:hover { ... }
// .button:active { ... }
// .button--primary { ... }
// .button--danger { ... }
// .button__icon { ... }

Example 3: Form with Nesting

.form {
    background: #f9f9f9;
    padding: 25px;
    border-radius: 10px;

    &__group {
        margin-bottom: 20px;

        label {
            display: block;
            margin-bottom: 8px;
            font-weight: 600;
        }

        input, textarea {
            width: 100%;
            padding: 12px;
            border: 2px solid #ddd;
            border-radius: 6px;

            &:focus {
                outline: none;
                border-color: #667eea;
            }

            &::placeholder {
                color: #999;
            }
        }
    }
}

⚠️ Nesting Best Practices

❌ BAD: Too Deep (> 3-4 levels)

.page {
    .container {
        .sidebar {
            .widget {
                .header {
                    .title {
                        .icon {
                            // 7 levels deep! 😱
                            // Hard to read
                            // Specific selectors
                        }
                    }
                }
            }
        }
    }
}

✅ GOOD: Max 3-4 Levels

.widget {
    padding: 20px;

    &__header {
        border-bottom: 1px solid #ddd;
    }

    &__title {
        font-size: 24px;

        .icon {
            margin-right: 8px;
        }
    }
}

// Flat, readable, maintainable!

🚫 Common Mistakes to Avoid:

  1. Over-nesting: Don't nest more than 3-4 levels deep
  2. Mirroring HTML exactly: Nest only what makes sense
  3. Complex selectors: Deep nesting creates overly specific selectors
  4. Performance: Overly specific selectors can impact rendering

✨ Advanced: Nesting Media Queries

.sidebar {
    width: 300px;
    float: left;

    @media (max-width: 768px) {
        width: 100%;
        float: none;
    }

    .widget {
        margin-bottom: 20px;

        @media (max-width: 768px) {
            margin-bottom: 10px;
        }
    }
}

// Media queries inside elements!
// Much more maintainable

🎓 Key Takeaways:

  • Nesting mirrors HTML structure for better readability
  • The & selector refers to the parent
  • Use & for pseudo-classes (:hover), pseudo-elements (::before)
  • BEM works great with nesting: &__element, &--modifier
  • Keep nesting to 3-4 levels maximum
  • You can nest media queries inside selectors!
