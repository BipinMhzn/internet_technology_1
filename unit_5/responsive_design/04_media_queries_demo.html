1. Width-based Media Queries

Background color changes based on screen width

Red: < 576px | Orange: 576px+ | Blue: 768px+ | Green: 992px+ | Purple: 1200px+

/* Mobile First Approach */
.element { background: red; }

@media (min-width: 576px) {
    .element { background: orange; }
}

@media (min-width: 768px) {
    .element { background: blue; }
}

@media (min-width: 992px) {
    .element { background: green; }
}

@media (min-width: 1200px) {
    .element { background: purple; }
}

.grid {
    display: grid;
    grid-template-columns: 1fr; /* Mobile: 1 column */
    gap: 15px;
}

@media (min-width: 576px) {
    .grid { grid-template-columns: repeat(2, 1fr); } /* 2 columns */
}

@media (min-width: 768px) {
    .grid { grid-template-columns: repeat(3, 1fr); } /* 3 columns */
}

@media (min-width: 992px) {
    .grid { grid-template-columns: repeat(4, 1fr); } /* 4 columns */
}

3. Orientation Media Query

Rotate your device or resize the window to change orientation

@media (orientation: portrait) {
    /* Styles for portrait mode (height > width) */
}

@media (orientation: landscape) {
    /* Styles for landscape mode (width > height) */
}

4. Responsive Typography

This heading size changes with screen size

Mobile: 1.2rem | Tablet: 1.5rem | Desktop: 2rem

h3 {
    font-size: 1.2rem; /* Mobile */
}

@media (min-width: 768px) {
    h3 { font-size: 1.5rem; } /* Tablet */
}

@media (min-width: 992px) {
    h3 { font-size: 2rem; } /* Desktop */
}

5. Hiding/Showing Elements

✓ This element is HIDDEN on mobile (< 768px) and VISIBLE on larger screens
✓ This element is VISIBLE on mobile (< 768px) and HIDDEN on larger screens 
.hide-mobile {
    display: none; /* Hidden on mobile */
}

@media (min-width: 768px) {
    .hide-mobile {
        display: block; /* Visible on tablet and up */
    }
}

.hide-desktop {
    display: block; /* Visible on mobile */
}

@media (min-width: 768px) {
    .hide-desktop {
        display: none; /* Hidden on tablet and up */
    }
}

6. Dark Mode Preference

Dark Mode Detection

This element changes based on your system's dark mode preference

@media (prefers-color-scheme: dark) {
    .element {
        background: #2c3e50;
        color: white;
    }
}

@media (prefers-color-scheme: light) {
    .element {
        background: white;
        color: #2c3e50;
    }
}

7. Hover Capability Detection

Hover over this element (if your device supports hover) 
/* Only apply hover effects on devices that support hover */
@media (hover: hover) {
    .element:hover {
        background: #3498db;
    }
}

/* For touch devices */
@media (hover: none) {
    .element:active {
        background: #3498db;
    }
}

8. Print Media Query

Try printing this page (Ctrl+P or Cmd+P)

Some elements will be hidden, and styles will change for print

This element only appears when printing!

@media print {
    /* Hide elements not needed for print */
    .no-print {
        display: none !important;
    }

    /* Show print-only elements */
    .print-only {
        display: block !important;
    }

    /* Optimize for print */
    body {
        background: white;
        color: black;
    }
}
