# CSS Grid Examples - Unit 5

This folder contains comprehensive CSS Grid examples for teaching Internet Technology course at Pokhara University.

## Examples Overview

### Basic Concepts (Examples 1-4)
1. **01_basic_grid.html** - Introduction to CSS Grid
   - `display: grid`
   - `grid-template-columns`
   - `gap` property

2. **02_fr_unit.html** - Fractional Units
   - Understanding `fr` unit
   - Creating proportional columns
   - Equal vs unequal distributions

3. **03_repeat_function.html** - Repeat Function
   - `repeat()` syntax
   - `auto-fill` and `auto-fit`
   - `minmax()` for responsive layouts

4. **04_grid_rows.html** - Working with Rows
   - `grid-template-rows`
   - `row-gap` and `column-gap`
   - Different row heights

### Advanced Concepts (Examples 5-7)
5. **05_spanning_items.html** - Spanning Grid Items
   - `grid-column: span n`
   - `grid-row: span n`
   - Creating complex layouts

6. **06_grid_template_areas.html** - Grid Template Areas
   - Named grid areas
   - Visual layout definition
   - Complete page layout example

7. **07_alignment.html** - Grid Alignment
   - `justify-items` (horizontal)
   - `align-items` (vertical)
   - `place-items` shorthand

### Practical Applications (Examples 8-10)
8. **08_responsive_grid.html** - Responsive Design
   - Mobile-first approach
   - Media queries with grid
   - Breakpoint strategies

9. **09_photo_gallery.html** - Photo Gallery
   - Real-world application
   - Featured items with spanning
   - Hover effects and transitions

10. **10_dashboard_layout.html** - Dashboard Layout
    - Complete application layout
    - Sidebar and header structure
    - Responsive dashboard design
    - Nested grids

## Syllabus Coverage

These examples align with **Unit 5: Advanced Topics on CSS**, specifically section **5.2 CSS Grid**.

## Key Learning Outcomes

Students will learn to:
- Create grid containers and grid items
- Use various grid properties for layout control
- Implement responsive grid designs
- Build real-world layouts (galleries, dashboards)
- Combine grid with other CSS features

## Teaching Tips

1. Start with basic examples (1-4) and build up complexity
2. Use browser DevTools to inspect grid layouts
3. Encourage students to modify examples and experiment
4. Show responsive behavior by resizing browser window
5. Compare Grid with Flexbox for different use cases

## Browser Compatibility

All examples use modern CSS Grid features supported by:
- Chrome/Edge (latest)
- Firefox (latest)
- Safari (latest)
