Example 8: Responsive Grid Layout

Concept:

Mobile-First Approach - Start with mobile layout, then add breakpoints

Media Queries - Change grid columns based on screen size

Try resizing your browser window!

Code:

/* Mobile: 1 column */
.responsive-grid {
    display: grid;
    grid-template-columns: 1fr;
    gap: 15px;
}

/* Tablet: 2 columns (≥ 600px) */
@media (min-width: 600px) {
    .responsive-grid {
        grid-template-columns: repeat(2, 1fr);
    }
}

/* Desktop: 4 columns (≥ 900px) */
@media (min-width: 900px) {
    .responsive-grid {
        grid-template-columns: repeat(4, 1fr);
    }
}
