Example 1: Basic CSS Grid Layout

Concept:

display: grid - Creates a grid container

grid-template-columns - Defines column widths

gap - Sets space between grid items

Code:

.grid-container {
    display: grid;
    grid-template-columns: 200px 200px 200px;
    gap: 10px;
}
