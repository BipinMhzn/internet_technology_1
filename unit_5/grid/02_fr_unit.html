Example 2: Fractional Units (fr)

Concept:

fr unit - Represents a fraction of available space

1fr 2fr 1fr - Middle column is twice as wide as side columns

Code Example 1:

.grid-container {
    display: grid;
    grid-template-columns: 1fr 2fr 1fr;  /* Ratio: 1:2:1 */
    gap: 15px;
}

Unequal Columns (1fr 2fr 1fr)

1fr
2fr (Wider)
1fr

Code Example 2:

.grid-equal {
    display: grid;
    grid-template-columns: 1fr 1fr 1fr 1fr;  /* All equal */
    gap: 15px;
}
