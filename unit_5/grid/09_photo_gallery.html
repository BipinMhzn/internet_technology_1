Example 9: Responsive Photo Gallery

Practical Example: Photo Gallery

This gallery uses:

  • auto-fill for responsive columns
  • minmax(250px, 1fr) for flexible sizing
  • grid-column/row span for featured images
  • CSS transitions for hover effects

Code:

.gallery {
    display: grid;
    grid-template-columns: repeat(auto-fill, minmax(250px, 1fr));
    gap: 15px;
}

.featured {
    grid-column: span 2;
    grid-row: span 2;
}
