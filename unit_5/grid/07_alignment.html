Example 7: Grid Alignment Properties

Concept:

justify-items - Horizontal alignment (start, center, end)

align-items - Vertical alignment (start, center, end)

justify-items: start

justify-items: end

align-items: end

Quick Reference:

/* Horizontal alignment */
justify-items: start | center | end | stretch;

/* Vertical alignment */
align-items: start | center | end | stretch;

/* Shorthand for both */
place-items: <align-items> <justify-items>;
