Example 3: Repeat Function

Concept:

repeat() - Shorthand to repeat column/row definitions

repeat(4, 1fr) is same as 1fr 1fr 1fr 1fr

repeat(4, 1fr) - Four Equal Columns

grid-template-columns: repeat(4, 1fr);
Item 1
Item 2
Item 3
Item 4
Item 5
Item 6
Item 7
Item 8

repeat(3, 100px) - Three Fixed Width Columns

grid-template-columns: repeat(3, 100px);
100px
100px
100px
100px
100px
100px

Auto-fill with minmax (Responsive!)

This will automatically create as many columns as can fit!

grid-template-columns: repeat(auto-fill, minmax(150px, 1fr));

Try resizing the browser window!
