Example 3: CSS Transform Property

What is Transform?

Transform allows you to modify the coordinate space of an element.

You can rotate, scale, skew, or translate elements without affecting document flow.

Best part: Transforms are GPU-accelerated and very performant!

Basic Transform Functions

All Transform Functions:

Function Description Example
scale(x, y) Change size scale(1.5)
rotate(angle) Rotate element rotate(45deg)
translate(x, y) Move element translate(50px, 100px)
skew(x, y) Slant element skew(20deg, 10deg)
rotateX() 3D rotate on X-axis rotateX(180deg)
rotateY() 3D rotate on Y-axis rotateY(180deg)
rotateZ() 3D rotate on Z-axis rotateZ(45deg)

Why Use Transform?

  • ✅ GPU-accelerated - Smooth, 60fps animations
  • ✅ No layout reflow - Doesn't affect other elements
  • ✅ Combines with transitions - Easy to animate
  • ✅ 3D capabilities - Create depth and perspective

Best Practices:

/* ✅ GOOD - Animate transform (GPU accelerated) */
.element {
    transition: transform 0.3s;
}
.element:hover {
    transform: translateX(100px);
}

/* ❌ AVOID - Animate position (causes reflow) */
.element {
    transition: left 0.3s;
}
.element:hover {
    left: 100px;
}
