Example 7: Animation Properties

Complete Animation Property Reference

CSS animations have many properties that control their behavior:

1. animation-duration

Controls how long the animation takes to complete one cycle

1 second
animation-duration: 1s;
3 seconds
animation-duration: 3s;

2. animation-iteration-count

How many times the animation should repeat

3 times
animation-iteration-count: 3;

Refresh page to see

Infinite
animation-iteration-count: infinite;

3. animation-direction

Controls the direction of the animation

normal
animation-direction: normal;
/* Forward every time */
reverse
animation-direction: reverse;
/* Backward every time */
alternate
animation-direction: alternate;
/* Forward, then backward */
alternate-reverse
animation-direction: alternate-reverse;
/* Backward, then forward */

4. animation-fill-mode

Defines styles applied before/after animation runs

Refresh page to see the differences!

forwards
animation-fill-mode: forwards;
/* Retains final state */
backwards
animation-fill-mode: backwards;
animation-delay: 2s;
/* Applies start state during delay */
both
animation-fill-mode: both;
animation-delay: 2s;
/* Both before and after */

5. animation-play-state

Controls whether animation is running or paused

Hover to pause:

Hover to Pause
.box {
    animation: spin 2s linear infinite;
}

.box:hover {
    animation-play-state: paused;
}

6. Interactive Play Control

You can control animations with JavaScript!

Controlled

Complete Shorthand Syntax:

animation: name duration timing-function delay iteration-count direction fill-mode play-state;

/* Examples */
animation: slide 2s ease-in-out 0s infinite normal none running;

/* Shorthand (common values) */
animation: slide 2s infinite;
animation: pulse 1s ease-in-out infinite alternate;

All Animation Properties:

Property Description Values
animation-name @keyframes name none | keyframe-name
animation-duration Length of animation 0s (default) | time
animation-timing-function Speed curve ease | linear | ease-in | ease-out | ease-in-out
animation-delay Start delay 0s (default) | time
animation-iteration-count Repeat count 1 (default) | number | infinite
animation-direction Play direction normal | reverse | alternate | alternate-reverse
animation-fill-mode Before/after styles none | forwards | backwards | both
animation-play-state Running or paused running (default) | paused
