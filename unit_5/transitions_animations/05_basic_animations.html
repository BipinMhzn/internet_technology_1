Example 5: Basic CSS Animations

Transitions vs Animations

Feature Transitions Animations
Trigger Needs a state change (hover, focus, etc.) Starts automatically or on demand
States Two states (start and end) Multiple states (keyframes)
Loop Plays once per trigger Can loop infinitely
Control Limited control Full control (play, pause, direction)

Transition Example (Requires Hover)

Hover to trigger:

.box {
    transition: transform 0.5s;
}
.box:hover {
    transform: translateX(100px);
}

Only animates when you hover!

Animation Example (Automatic)

Plays automatically:

@keyframes slide {
    from { transform: translateX(0); }
    to { transform: translateX(100px); }
}

.box {
    animation: slide 2s infinite alternate;
}

Animates automatically and loops infinitely!

Common Animation Examples

Pulse

@keyframes pulse {
    0% { transform: scale(1); }
    50% { transform: scale(1.2); }
    100% { transform: scale(1); }
}

Bounce

@keyframes bounce {
    0%, 100% {
        transform: translateY(0);
    }
    50% {
        transform: translateY(-30px);
    }
}

Rotate

@keyframes rotate {
    from { transform: rotate(0deg); }
    to { transform: rotate(360deg); }
}

Fade

@keyframes fade {
    0%, 100% { opacity: 1; }
    50% { opacity: 0.3; }
}

Color Change

@keyframes colorChange {
    0% { background: red; }
    25% { background: yellow; }
    50% { background: green; }
    75% { background: blue; }
    100% { background: red; }
}

Animation Syntax:

/* Step 1: Define keyframes */
@keyframes animationName {
    from { /* starting styles */ }
    to { /* ending styles */ }
}

/* OR with percentages */
@keyframes animationName {
    0% { /* starting styles */ }
    50% { /* middle styles */ }
    100% { /* ending styles */ }
}

/* Step 2: Apply animation */
.element {
    animation: animationName duration timing-function delay iteration-count direction;
}

/* Shorthand example */
.element {
    animation: slide 2s ease-in-out 0s infinite alternate;
}

Key Properties:

  • animation-name - Name of @keyframes
  • animation-duration - How long (e.g., 2s)
  • animation-timing-function - Easing (ease, linear, etc.)
  • animation-delay - Wait before starting
  • animation-iteration-count - How many times (number or infinite)
  • animation-direction - normal, reverse, alternate, alternate-reverse

When to Use Animations:

  • ✅ Loading spinners
  • ✅ Attention-grabbing elements
  • ✅ Background effects
  • ✅ Multi-step sequences
  • ✅ Continuous motion
