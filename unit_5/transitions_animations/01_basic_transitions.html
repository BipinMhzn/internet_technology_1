Example 1: Basic CSS Transitions

What are CSS Transitions?

Transitions allow property changes to occur smoothly over a specified duration, rather than instantly.

Syntax: transition: property duration timing-function delay;

Without vs With Transition

Hover over the boxes to see the difference!

Without Transition

Hover Me
(Instant) 
.box:hover {
    background-color: #C2185B;
    width: 180px;
    height: 180px;
}
/* No transition - changes instantly! */

With Transition

Hover Me
(Smooth) 
.box {
    transition: all 0.3s;
}

.box:hover {
    background-color: #1976D2;
    width: 180px;
    height: 180px;
}
/* Changes smoothly over 0.3s */

Key Points:

  • transition: all - Applies to all properties that change
  • Duration - Time in seconds (s) or milliseconds (ms)
  • Common durations: 0.1s to 0.5s for UI interactions
  • Transitions work on hover, focus, active states

Syntax:

/* Shorthand */
transition: all 0.3s;

/* Full syntax */
transition: property duration timing-function delay;

/* Examples */
transition: background-color 0.3s;
transition: all 0.3s ease-in-out;
transition: width 0.5s, height 0.5s;
