Animations & Transitions Used:

  • Page Load: Fade in down animation for title
  • Cards: Staggered fade in up animations
  • Hover: Lift effect with enhanced shadow
  • Image: Zoom effect on hover
  • Badge: Continuous pulse animation
  • Stars: Sequential bounce on card hover
  • Button: Ripple effect + scale on hover/active
  • Button Click: Loading spinner animation

Key Techniques:

/* 1. Staggered Animations */
.card:nth-child(1) { animation-delay: 0.1s; }
.card:nth-child(2) { animation-delay: 0.2s; }
.card:nth-child(3) { animation-delay: 0.3s; }

/* 2. Multiple Hover Effects */
.card:hover {
    transform: translateY(-10px);
    box-shadow: 0 20px 50px rgba(0,0,0,0.3);
}

.card:hover .image {
    transform: scale(1.1);
}

/* 3. Ripple Effect */
.btn::before {
    transition: width 0.6s, height 0.6s;
}

.btn:hover::before {
    width: 300px;
    height: 300px;
}

/* 4. Sequential Star Animation */
.star:nth-child(1) { animation-delay: 0s; }
.star:nth-child(2) { animation-delay: 0.1s; }
/* ... etc */

/* 5. Loading State */
.btn.loading::after {
    content: '';
    border: 2px solid white;
    border-top-color: transparent;
    animation: spin 0.6s linear infinite;
}

Interaction Tips:

  • Hover over cards to see lift and zoom effects
  • Notice the sequential star bounce on hover
  • Click "Buy Now" to see loading animation
  • Observe the staggered card entrance on page load
  • Watch the pulsing "NEW" and "SALE" badges
