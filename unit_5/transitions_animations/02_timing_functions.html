Example 2: Transition Timing Functions

What are Timing Functions?

Timing functions control the pace of the transition over its duration.

They define how the animation accelerates and decelerates.

Timing Function Descriptions:

Function Description Use Case
linear Constant speed from start to end Loading bars, spinners
ease Slow start, fast middle, slow end (default) Most UI interactions
ease-in Slow start, fast end Items leaving the screen
ease-out Fast start, slow end Items entering the screen
ease-in-out Slow start and end Smooth, natural movement
cubic-bezier() Custom timing curve Unique, branded animations

Code Examples:

/* Linear - constant speed */
transition: all 0.3s linear;

/* Ease (default) - natural feel */
transition: all 0.3s ease;

/* Ease-in - accelerates */
transition: all 0.3s ease-in;

/* Ease-out - decelerates */
transition: all 0.3s ease-out;

/* Ease-in-out - smooth both ends */
transition: all 0.3s ease-in-out;

/* Custom cubic-bezier - bouncy effect */
transition: all 0.3s cubic-bezier(0.68, -0.55, 0.265, 1.55);
