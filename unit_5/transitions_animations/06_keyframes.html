Example 6: Advanced Keyframes

What are Keyframes?

Keyframes define the intermediate steps in an animation sequence.

You can specify styles at multiple points (0%, 25%, 50%, 75%, 100%) to create complex animations.

Multi-Step Animation

This box moves in a square pattern while changing color and shape!

@keyframes complexPath {
    0% {
        transform: translate(0, 0);
        background-color: #FF5722;
        border-radius: 10px;
    }
    25% {
        transform: translate(100px, -50px);
        background-color: #FFC107;
        border-radius: 50%;
    }
    50% {
        transform: translate(100px, 50px);
        background-color: #4CAF50;
        border-radius: 0;
    }
    75% {
        transform: translate(-100px, 50px);
        background-color: #2196F3;
        border-radius: 50%;
    }
    100% {
        transform: translate(0, 0);
        background-color: #FF5722;
        border-radius: 10px;
    }
}

Walking Animation (with Direction Change)

🚶
@keyframes walk {
    0% {
        transform: translateX(-200px) scaleX(1);
    }
    48% {
        transform: translateX(200px) scaleX(1);
    }
    50% {
        transform: translateX(200px) scaleX(-1);  /* Flip! */
    }
    98% {
        transform: translateX(-200px) scaleX(-1);
    }
    100% {
        transform: translateX(-200px) scaleX(1);
    }
}

Heartbeat Effect

❤️
@keyframes heartbeat {
    0%, 100% { transform: scale(1); }
    10%, 30% { transform: scale(0.9); }
    20%, 40%, 60%, 80% { transform: scale(1.1); }
    50%, 70% { transform: scale(1.05); }
}

Multiple keyframe points create a realistic heartbeat rhythm!

Loading Dots (Staggered Animation)

@keyframes loadingDots {
    0%, 80%, 100% {
        opacity: 0;
        transform: scale(0.5);
    }
    40% {
        opacity: 1;
        transform: scale(1);
    }
}

.dot:nth-child(1) { animation-delay: 0s; }
.dot:nth-child(2) { animation-delay: 0.2s; }
.dot:nth-child(3) { animation-delay: 0.4s; }

Typewriter Effect

Hello, I'm a typewriter!
@keyframes typewriter {
    0% { width: 0; }
    50% { width: 100%; }
    100% { width: 100%; }
}

@keyframes blink {
    0%, 100% { border-right-color: transparent; }
    50% { border-right-color: #333; }
}

.text {
    overflow: hidden;
    white-space: nowrap;
    border-right: 3px solid #0F0;
    animation:
        typewriter 4s steps(30) infinite,
        blink 0.75s step-end infinite;
}

Note: steps(30) creates a stepped animation instead of smooth!

Wave Text Animation

@keyframes wave {
    0%, 100% {
        transform: translateY(0) rotate(0deg);
    }
    25% {
        transform: translateY(-10px) rotate(-10deg);
    }
    75% {
        transform: translateY(-10px) rotate(10deg);
    }

.wave-container span {
    animation: wave 1.5s ease-in-out infinite;
}

span:nth-child(1) { animation-delay: 0s; }
span:nth-child(2) { animation-delay: 0.1s; }
span:nth-child(3) { animation-delay: 0.2s; }

Keyframe Best Practices:

  • ✅ Use meaningful percentages (0%, 25%, 50%, 75%, 100%)
  • ✅ Can use from (0%) and to (100%) for simple animations
  • ✅ Combine with animation-delay for staggered effects
  • ✅ Use steps() timing for frame-by-frame animations
  • ✅ Test performance - complex keyframes can be resource-intensive

Timing Function in Keyframes:

/* Apply timing to entire animation */
.element {
    animation: myAnimation 2s ease-in-out;
}

/* Apply timing between specific keyframes */
@keyframes myAnimation {
    0% {
        animation-timing-function: ease-in;
    }
    50% {
        animation-timing-function: ease-out;
    }
    100% { }
}
