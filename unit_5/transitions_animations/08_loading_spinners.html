Example 8: Loading Spinners & Indicators

Practical Animation Examples

Loading animations improve user experience by showing that something is happening.

All examples use pure CSS - no images or JavaScript required!

Basic Spinner

@keyframes spin {
    to {
        transform: rotate(360deg);
    }
}

.spinner {
    border: 5px solid #E0E0E0;
    border-top-color: #2196F3;
    border-radius: 50%;
    animation: spin 1s linear infinite;
}

Dual Ring

.spinner {
    border: 5px solid #E0E0E0;
    border-top-color: #2196F3;
    border-bottom-color: #FF9800;
    border-radius: 50%;
    animation: spin 0.8s linear infinite;
}

Pulsing Ring

@keyframes pulse-ring {
    0% {
        transform: scale(0.5);
        opacity: 1;
    }
    100% {
        transform: scale(1.2);
        opacity: 0;
    }
}

Bouncing Dots

@keyframes bounce {
    0%, 80%, 100% {
        transform: scale(0);
    }
    40% {
        transform: scale(1);
    }
}

div:nth-child(1) {
    animation-delay: -0.32s;
}

Bar Loader

@keyframes bar-loader {
    0%, 80%, 100% {
        height: 20px;
    }
    40% {
        height: 50px;
    }
}

Circle Loader

/* 8 dots positioned in circle */
/* Staggered animation delays */

div:nth-child(1) {
    animation-delay: 0s;
}
div:nth-child(2) {
    animation-delay: 0.1s;
}

Progress Bar

@keyframes progress {
    0% { left: -100%; }
    100% { left: 100%; }
}

.progress-bar::after {
    animation: progress 1.5s infinite;
}

Skeleton Loader

@keyframes skeleton-loading {
    0% {
        background-position: -200px 0;
    }
    100% {
        background-position: 200px 0;
    }
}

Ripple Effect

@keyframes ripple {
    0% {
        transform: scale(0);
        opacity: 1;
    }
    100% {
        transform: scale(1);
        opacity: 0;
    }
}

When to Use Each Loader:

  • Basic Spinner: General loading, API calls
  • Dual Ring: Processes with multiple steps
  • Pulsing Ring: Waiting states, background processes
  • Bouncing Dots: File uploads, data syncing
  • Bar Loader: Music/audio players, voice recording
  • Circle Loader: Longer operations, patience required
  • Progress Bar: Top of page loading, indeterminate progress
  • Skeleton Loader: Content placeholders, page loading
  • Ripple Effect: Button clicks, user actions

Best Practices:

  • ✅ Use subtle animations (not too fast, not too slow)
  • ✅ Match loader style to your brand
  • ✅ Provide context (e.g., "Loading your data...")
  • ✅ Use skeleton loaders for better perceived performance
  • ✅ Test with accessibility tools (screen readers)
  • ❌ Don't use too many loaders on one page
  • ❌ Don't make loaders too large or distracting
