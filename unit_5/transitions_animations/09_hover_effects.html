Example 9: Hover Effects & Microinteractions

What are Microinteractions?

Small, subtle animations that provide feedback to user actions.

They make interfaces feel responsive and alive!

Hover over the elements below to see them in action!

Button Effects

Glow Effect

.btn:hover {
    box-shadow:
        0 0 20px #2196F3,
        0 0 40px #2196F3,
        0 0 60px #2196F3;
}

Slide In Border

.btn::before {
    left: -100%;
    transition: left 0.3s;
}
.btn:hover::before {
    left: 0;
}

Shake Effect

@keyframes shake {
    0%, 100% { translateX(0); }
    25% { translateX(-10px); }
    75% { translateX(10px); }
}
.btn:hover {
    animation: shake 0.5s;
}

Gradient Shift

.btn {
    background: linear-gradient(
        90deg, #667eea, #764ba2
    );
    background-size: 200% 100%;
}
.btn:hover {
    background-position: 100% 0;
}

Ripple Effect

.btn::before {
    width: 0; height: 0;
    transition: width 0.6s,
                height 0.6s;

.btn:hover::before {
    width: 300px;

Best Practices for Hover Effects:

  • ✅ Keep transitions short (0.2s - 0.5s)
  • ✅ Use transform and opacity for best performance
  • ✅ Provide visual feedback immediately
  • ✅ Make effects subtle and purposeful
  • ✅ Test on touch devices (no hover on mobile!)
  • ❌ Don't overuse effects (less is more)
  • ❌ Don't make effects too slow or distracting
  • ❌ Don't rely solely on hover for important information

Mobile Considerations:

/* Show hover effects only on devices that support hover */
@media (hover: hover) {
    .btn:hover {
        transform: scale(1.1);
    }
}

/* Alternative for touch devices */
.btn:active {
    transform: scale(0.95);
}
