Example 6: Flex Item Properties

Concept:

flex-grow - How much item grows relative to others

flex-shrink - How much item shrinks relative to others

flex-basis - Initial size before growing/shrinking

flex - Shorthand for grow, shrink, and basis

flex-grow Property

.item1 { flex-grow: 1; }  /* Takes 1 part of extra space */
.item2 { flex-grow: 2; }  /* Takes 2 parts of extra space */
.item3 { flex-grow: 3; }  /* Takes 3 parts of extra space */

Items grow proportionally: 1:2:3 ratio

flex-grow: 1
flex-grow: 2
flex-grow: 3

flex-shrink Property

.item1 { flex-shrink: 0; width: 200px; }  /* Won't shrink */
.item2 { flex-shrink: 1; width: 200px; }  /* Shrinks 1x */
.item3 { flex-shrink: 2; width: 200px; }  /* Shrinks 2x */

Try resizing browser - item with flex-shrink: 0 won't shrink!

flex-shrink: 0
(Won't shrink)
flex-shrink: 1
flex-shrink: 2
(Shrinks more)

flex-basis Property

.item1 { flex-basis: 100px; }  /* Initial size 100px */
.item2 { flex-basis: 200px; }  /* Initial size 200px */
.item3 { flex-basis: auto; }   /* Size based on content */

Sets the initial main size before extra space is distributed

flex-basis: 100px
flex-basis: 200px
flex-basis: auto

flex Shorthand (Most Common)

flex: [grow] [shrink] [basis]

/* Common values: */
flex: 1;        /* Same as: flex: 1 1 0% */
flex: 2;        /* Same as: flex: 2 1 0% */
flex: none;     /* Same as: flex: 0 0 auto */
flex: auto;     /* Same as: flex: 1 1 auto */

Using flex: 1 and flex: 2

.item1 { flex: 1; }  /* Takes 1 part */
.item2 { flex: 2; }  /* Takes 2 parts (twice as wide) */
.item3 { flex: 1; }  /* Takes 1 part */
flex: 1
flex: 2 (Wider)
flex: 1

Using flex: none

.item { flex: none; }  /* Won't grow or shrink */
flex: 1
flex: none
(Fixed size)
flex: 1

Quick Guide:

Property Use Case
flex: 1 Equal width items
flex: 2 Item twice as wide as flex: 1
flex: none Fixed size, won't grow/shrink
flex: auto Size based on content, can grow
