Example 3: Justify Content

Concept:

justify-content - Aligns items along the main axis (horizontal if flex-direction: row)

Controls: How extra space is distributed

justify-content: flex-start (Default)

justify-content: flex-start;  /* Items at the start */
Box 1
Box 2
Box 3

justify-content: flex-end

justify-content: flex-end;  /* Items at the end */
Box 1
Box 2
Box 3

justify-content: center

justify-content: center;  /* Items centered */
Box 1
Box 2
Box 3

justify-content: space-between

justify-content: space-between;  /* Equal space BETWEEN items */

First item at start, last item at end, equal space between

Box 1
Box 2
Box 3

justify-content: space-around

justify-content: space-around;  /* Equal space AROUND items */

Space on sides is half of space between items

Box 1
Box 2
Box 3

justify-content: space-evenly

justify-content: space-evenly;  /* Equal space everywhere */

All spaces are equal (including edges)

Box 1
Box 2
Box 3

Quick Reference:

  • flex-start - Pack items at start
  • flex-end - Pack items at end
  • center - Center items
  • space-between - Space between items only
  • space-around - Space around items (half on edges)
  • space-evenly - Equal space everywhere
