Example 1: Introduction to Flexbox

Concept:

Flexbox - One-dimensional layout method for arranging items in rows or columns

display: flex - Creates a flex container

Flex items - Direct children of flex container

Without Flexbox (Normal Block Elements)

.container-normal {
    /* No flexbox - default block behavior */
}

With Flexbox (display: flex)

.container-flex {
    display: flex;  /* Items arranged in a row */
}

Notice: Items are now in a row instead of stacked vertically!

Key Points:

  • Flexbox works on a single axis (row or column)
  • By default, items are arranged in a row (left to right)
  • Items are placed side-by-side without needing floats
  • Great for navigation bars, toolbars, and simple layouts
