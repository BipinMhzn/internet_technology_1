Example 7: Align Self and Order

Concept:

align-self - Override align-items for individual flex items

order - Control the visual order of flex items

align-self Property

.container { align-items: center; }  /* Default for all items */

.item1 { align-self: flex-start; }   /* Override for this item */
.item2 { align-self: flex-end; }     /* Override for this item */

Container has align-items: center, but items override it individually

order Property

/* HTML Order: Box 1, Box 2, Box 3, Box 4 */

.box1 { order: 3; }   /* Appears last */
.box2 { order: 1; }   /* Appears second */
.box3 { order: 2; }   /* Appears third */
.box4 { order: -1; }  /* Appears first (negative values come first) */

Default order is 0. Lower values appear first.

Practical Example: Responsive Reordering

/* Desktop: Logo, Nav, Search */
.logo { order: 1; }
.nav { order: 2; }
.search { order: 3; }

/* Mobile: Logo, Search, Nav */
@media (max-width: 768px) {
    .logo { order: 1; }
    .search { order: 2; }
    .nav { order: 3; }
}

Change visual order without changing HTML structure!

Quick Reference:

align-self values:

  • auto - Use container's align-items value (default)
  • flex-start - Align to start of cross axis
  • flex-end - Align to end of cross axis
  • center - Center on cross axis
  • baseline - Align text baselines
  • stretch - Stretch to fill container

order:

  • Default: 0
  • Negative values: Appear before 0
  • Positive values: Appear after 0
  • Same order: Uses source HTML order
