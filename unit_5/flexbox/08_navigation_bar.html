Example 8: Responsive Navigation Bar

Try resizing your browser to see the responsive behavior!

Flexbox Properties Used:

/* Main Navigation Container */
.nav-container {
    display: flex;
    justify-content: space-between;  /* Logo left, menu center, actions right */
    align-items: center;             /* Vertically center all items */
}

/* Navigation Menu */
.nav-menu {
    display: flex;                   /* Horizontal menu items */
    list-style: none;
    gap: 0;                          /* No gap (padding in links instead) */
}

/* Action Buttons */
.nav-actions {
    display: flex;
    gap: 10px;                       /* Space between buttons */
    align-items: center;
}

/* Mobile Responsive */
@media (max-width: 768px) {
    .nav-container {
        flex-direction: column;      /* Stack vertically */
        align-items: stretch;        /* Full width items */
    }

    .nav-menu {
        flex-direction: column;      /* Vertical menu */
    }

    .nav-actions {
        justify-content: center;     /* Center buttons */
    }
}

Key Features:

  • Desktop: Logo on left, menu in center, buttons on right
  • Mobile: Stacked layout with full-width items
  • Flexbox Benefits:
    • Easy alignment (vertical centering)
    • Flexible spacing (space-between)
    • Simple responsive design (flex-direction change)
    • No complex positioning or floats needed

Common Navigation Patterns:

1. Logo Left, Menu Right

.nav {
    display: flex;
    justify-content: space-between;
}

2. Everything Centered

.nav {
    display: flex;
    flex-direction: column;
    align-items: center;
}

3. Logo, Menu, Search (Three Sections)

.nav {
    display: flex;
    justify-content: space-between;
}

.menu {
    flex: 1;                    /* Menu takes available space */
    display: flex;
    justify-content: center;    /* Center menu items */
}
