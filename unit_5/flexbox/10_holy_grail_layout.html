The Holy Grail Layout

The "Holy Grail" layout is a classic web design pattern with:

  • Header at the top
  • Three columns in the middle (nav, content, ads)
  • Footer at the bottom
  • Footer always at bottom, even with little content
  • Center column is fluid (grows/shrinks)
  • Side columns have fixed widths

Before Flexbox, this layout was difficult to achieve. Now it's simple!

How It Works

This layout uses nested flexbox containers:

1. Body (Vertical Flex Container)

body {
    display: flex;
    flex-direction: column;
    min-height: 100vh;        /* Full viewport height */
}

.main-container {
    flex: 1;                  /* Takes remaining space */
}

2. Main Container (Horizontal Flex Container)

.main-container {
    display: flex;            /* Horizontal layout */
}

.nav {
    width: 200px;
    flex-shrink: 0;           /* Fixed width, won't shrink */
}

.content {
    flex: 1;                  /* Takes all available space */
}

.ads {
    width: 250px;
    flex-shrink: 0;           /* Fixed width, won't shrink */
}

3. Responsive Layout

@media (max-width: 968px) {
    .main-container {
        flex-direction: column;  /* Stack vertically on mobile */
    }

    .nav, .ads {
        width: 100%;             /* Full width */
    }

    /* Reorder using flexbox order property */
    .nav { order: 1; }
    .content { order: 2; }
    .ads { order: 3; }
}

Key Benefits

  • ✅ Footer always at bottom (even with minimal content)
  • ✅ Equal height columns automatically
  • ✅ Easy to make responsive
  • ✅ Clean, semantic HTML
  • ✅ No complex calculations or hacks
  • ✅ Easy to reorder columns on mobile

  2. Notice how the footer stays at the bottom
  3. On mobile, columns stack vertically
