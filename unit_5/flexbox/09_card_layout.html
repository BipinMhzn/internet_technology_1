Example 9: Flexible Card Layout

Nested Flexbox Example

This example demonstrates:

  • Flex container for card layout
  • Nested flex inside each card for content layout
  • flex: 1 to push footer to bottom
  • Responsive wrapping with flex-wrap

Code Explanation:

/* Card Container - Wrapping Flex Layout */
.card-container {
    display: flex;
    flex-wrap: wrap;           /* Cards wrap to new lines */
    gap: 20px;                 /* Space between cards */
}

/* Each Card - Flexible Width */
.card {
    flex: 1 1 300px;           /* grow, shrink, min-width 300px */

    /* Card itself is a flex container */
    display: flex;
    flex-direction: column;    /* Stack image and content vertically */
}

/* Card Content Area */
.card-content {
    padding: 20px;
    flex: 1;                   /* Takes remaining space */

    /* Also a flex container */
    display: flex;
    flex-direction: column;
}

/* Card Description */
.card-description {
    flex: 1;                   /* Pushes footer to bottom */
}

/* Card Footer */
.card-footer {
    display: flex;
    justify-content: space-between;  /* Price left, button right */
    align-items: center;             /* Vertically centered */
}

Key Concepts:

  • flex: 1 1 300px - Cards grow/shrink but minimum 300px wide
  • flex-wrap: wrap - Cards wrap to next line when needed
  • Nested flexbox - Container, card, and card-content all use flexbox
  • flex: 1 on description - Pushes footer to bottom regardless of content length
  • gap property - Clean spacing without margins
