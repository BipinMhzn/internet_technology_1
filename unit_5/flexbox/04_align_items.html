Example 4: Align Items

Concept:

align-items - Aligns items along the cross axis (vertical if flex-direction: row)

Think: justify-content = horizontal, align-items = vertical (for row direction)

Perfect Centering Trick:

.container {
    display: flex;
    justify-content: center;  /* Horizontal center */
    align-items: center;      /* Vertical center */
    height: 100vh;
}

This centers content both horizontally and vertically!
