📋 Selection Methods Comparison

Method Returns Live? Use Case
getElementById() Single element No Select by unique ID
getElementsByClassName() HTMLCollection Yes Select by class name
getElementsByTagName() HTMLCollection Yes Select by tag name
querySelector() Single element (first) No CSS selector (first match)
querySelectorAll() NodeList No CSS selector (all matches)

⚡ Live vs Static Collections

Important Difference:

  • Live Collections (HTMLCollection): Automatically updates when DOM changes
    • getElementsByClassName()
    • getElementsByTagName()
  • Static Collections (NodeList): Snapshot at selection time
    • querySelectorAll()

🎯 Best Practices

When to Use What?

  1. getElementById(): When you have a unique ID (fastest)
  2. querySelector(): When you need first element with complex selector
  3. querySelectorAll(): When you need all matching elements (most flexible)
  4. getElementsByClassName(): When you need a live collection by class
  5. getElementsByTagName(): When you need all elements of specific tag
