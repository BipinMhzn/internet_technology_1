🐞 Debugger Statement & DevTools

⚠️ IMPORTANT: Open DevTools (F12) and switch to "Sources" tab to use the debugger!

🎯 Learning Objectives:

  • Understand the debugger statement
  • Learn to set breakpoints in code
  • Step through code execution
  • Inspect variables and call stack
  • Use browser DevTools effectively
The debugger Statement: function calculateTotal(items) { let total = 0; for (let item of items) { debugger; // 🛑 Execution pauses here total += item.price * item.quantity; } return total; }

📚 How It Works:

When JavaScript encounters the debugger; statement:

  1. If DevTools is open, execution pauses at that line
  2. You can inspect variables, call stack, and scope
  3. Use controls to step through code line by line
  4. If DevTools is closed, the statement is ignored

DevTools Controls:

▶️ Resume (F8)

Continue execution until next breakpoint or debugger statement

⤵️ Step Over (F10)

Execute current line and move to the next line (don't enter functions)

⬇️ Step Into (F11)

If current line has a function call, step into that function

⬆️ Step Out (Shift+F11)

Execute rest of current function and return to caller
