🛡️ Error Handling: try-catch Basics

🎯 Learning Objectives:

  • Understand how to catch and handle errors gracefully
  • Learn the try-catch-finally syntax
  • Prevent application crashes from runtime errors
Basic Syntax: try { // Code that might throw an error riskyOperation(); } catch (error) { // Code to handle the error console.log("Error:", error.message); } finally { // Code that always runs (optional) console.log("Cleanup code"); }
