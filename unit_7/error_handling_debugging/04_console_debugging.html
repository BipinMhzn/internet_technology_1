🐛 Console Debugging Methods

⚠️ IMPORTANT: Open the Browser Console (F12 or Cmd+Option+I) to see the output!

🎯 Learning Objectives:

  • Master different console methods for debugging
  • Learn when to use each console method
  • Understand console formatting and styling
  • Use console for performance measurement

Common Console Methods:

Method Purpose Example
console.log() General purpose logging console.log("Hello");
console.error() Log error messages console.error("Error!");
console.warn() Log warning messages console.warn("Warning!");
console.info() Log informational messages console.info("Info");
console.table() Display data in table format console.table(users);
console.group() Group related logs console.group("Group");
console.time() Start a timer console.time("timer");
console.count() Count function calls console.count("clicks");
console.trace() Show stack trace console.trace();
console.assert() Log if condition is false console.assert(x > 0);
