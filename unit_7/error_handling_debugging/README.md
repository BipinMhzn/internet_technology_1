# Unit 7.2: Error Handling and Debugging - Practical Examples

## 📚 Example Files Overview

This directory contains interactive HTML examples for teaching error handling and debugging to BCSIT students.

### Example Files

| File | Topic | Description |
|------|-------|-------------|
| `01_try_catch_basics.html` | try-catch | Basic error handling with try-catch-finally |
| `02_error_types.html` | Error Types | Different JavaScript error types |
| `03_throw_custom_errors.html` | Custom Errors | Throwing and creating custom errors |
| `04_console_debugging.html` | Console Methods | console.log, table, group, time, etc. |
| `05_debugger_statement.html` | Debugger | Using debugger statement and DevTools |

## 🎯 Learning Path

### For Students:
1. Start with `01_try_catch_basics.html` - understand error handling
2. Learn `02_error_types.html` - know different error types
3. Study `03_throw_custom_errors.html` - create your own errors
4. Practice `04_console_debugging.html` - master console methods
5. Debug with `05_debugger_statement.html` - use DevTools effectively

### For Instructors:
- Each file is self-contained and browser-ready
- Examples demonstrate real-world scenarios
- Interactive buttons for hands-on learning
- Console integration for debugging practice
- DevTools usage demonstrated

## 💡 How to Use

### In Classroom:
1. Open `index.html` for navigation or any example directly
2. Click "Run Example" buttons to see demonstrations
3. Open browser console (F12) for additional outputs
4. For debugger examples, open DevTools → Sources tab
5. Encourage students to experiment and modify code

### For Practice:
- Try breaking the code intentionally
- Add your own error scenarios
- Practice using different console methods
- Set breakpoints and step through code
- Inspect variables and call stack

## 🔍 Key Concepts Covered

### Error Handling
- **try-catch-finally**: Catching and handling errors
- **Error Types**: ReferenceError, TypeError, RangeError, URIError
- **Throwing Errors**: Creating custom errors with throw
- **Custom Error Classes**: Extending Error class

### Debugging
- **Console Methods**: log, error, warn, info, table, group
- **Advanced Console**: time, count, trace, assert
- **Debugger Statement**: Pausing execution
- **DevTools**: Breakpoints, stepping, call stack inspection
- **Variable Inspection**: Watching values change

## 📝 Practice Exercises

After completing the examples, students should be able to:

1. **Error Handling Exercise**: Create a user registration form with validation that throws appropriate errors
2. **Custom Error Exercise**: Build an API wrapper with custom error types
3. **Console Exercise**: Debug a shopping cart using various console methods
4. **Debugger Exercise**: Fix bugs in provided code using breakpoints

## ⚠️ Common Mistakes to Avoid

1. **Not handling errors**: Always use try-catch for risky operations
2. **Swallowing errors**: Don't catch errors without logging or handling them
3. **Generic error messages**: Be specific about what went wrong
4. **Leaving debugger statements**: Remove before production
5. **Not using DevTools**: Learn to use browser debugging tools effectively
