🔢 Interactive Closure Counter

🎯 Objective:

Understand how closures create private variables that maintain their state independently.

Key Concept: Each counter has its own private "count" variable that cannot be accessed or modified directly!

function createCounter(name, start = 0) { let count = start; // ← Private variable (closure) return { increment: () => ++count, decrement: () => --count, reset: () => count = start, getValue: () => count, getName: () => name }; }
Counter A
0
Counter B
100
Counter C
50

💡 What's Happening?

  • Each counter is independent: They each have their own private "count" variable
  • Data Privacy: You cannot access the "count" directly - try counterA.count in the console (it's undefined!)
  • Closure Magic: The inner functions (increment, decrement, etc.) remember their environment
  • State Preservation: Each counter maintains its state between function calls

🔬 Experiment:

  1. Open the browser console (F12)
  2. Type: counterA - You'll see the object with methods
  3. Type: counterA.count - It's undefined (private!)
  4. Type: counterA.getValue() - This works! (public method)
  5. Notice how each counter maintains its own separate state
