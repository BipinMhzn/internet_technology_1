🏭 Closure Function Factory

🎯 Objective:

Learn how closures can create specialized functions that "remember" configuration values.

Function Factory: A function that creates and returns other customized functions.

// The Factory Function function createMultiplier(factor) { // 'factor' is captured in closure return function(number) { return number * factor; }; } // Creating Specialized Functions const double = createMultiplier(2); const triple = createMultiplier(3); const times10 = createMultiplier(10); // Using the Functions double(5); // 10 triple(5); // 15 times10(5); // 50
Double (×2)
10
Triple (×3)
15
Times 10 (×10)
50

💡 How It Works:

  1. createMultiplier(factor) returns a new function
  2. The returned function "remembers" the factor value
  3. Each created function has its own independent closure
  4. double, triple, and times10 are separate functions with different factors

More Function Factory Examples:

// Example 1: Greeting Factory function createGreeter(greeting) { return function(name) { return greeting + ", " + name + "!"; }; } const sayHello = createGreeter("Hello"); const sayNamaste = createGreeter("Namaste"); sayHello("John"); // "Hello, John!" sayNamaste("Ram"); // "Namaste, Ram!"
// Example 2: Tax Calculator Factory function createTaxCalculator(taxRate) { return function(amount) { return amount * (1 + taxRate); }; } const withVAT = createTaxCalculator(0.13); // 13% VAT const withServiceTax = createTaxCalculator(0.10); // 10% Service Tax withVAT(1000); // 1130 withServiceTax(1000); // 1100
// Example 3: Power Function Factory function createPowerFunction(exponent) { return function(base) { return Math.pow(base, exponent); }; } const square = createPowerFunction(2); const cube = createPowerFunction(3); square(5); // 25 cube(3); // 27

🎓 Key Takeaways:

  • Reusability: Create specialized functions from a general pattern
  • Configuration: Pre-configure functions with specific parameters
  • Encapsulation: Each created function has its own private configuration
  • DRY Principle: Don't Repeat Yourself - define the pattern once, create many variations
