Vue.js Introduction

Vue.js is a progressive JavaScript framework for building user interfaces.

Key concepts: Template syntax, Directives (v-bind, v-if, v-for), Reactive data

Example 1: Data Binding

Hello, {{ name }}!

College: {{ college }}

Message: {{ greeting }}

Example 2: Directives

Student List:

  1. {{ student.name }} (Age: {{ student.age }}) - Senior - Junior

Total: {{ students.length }} students

Example 3: Counter (Reactivity)

Count: {{ count }}
